# 타입 추론 

타입스크립트의 경우 점진적 타입 시스템으로
너무 당연한 경우엔 굳이 타입 주석을 달지 않아도 본인이 추론한다. 

let a = 10; 이라 작성할 때  a에 커서를 올리면 a : number 라고 출력이 된다 
즉 너무 당연한 부분에 대해선 본인이 알아서 타입 주석을 넘겨준다. 

## 선언만 하고 값을 안 넣는 경우 
let d; 이런식으로 선언만 진행하고 값을 안 넣는다면 any 라는 타입 주석을 붙여주는데 
any의 경우 모든 값의 슈퍼타입이므로 추론이 되지 않는 경우엔 any를 적용한다. 

이후 d = 10; 을 넣게 되면 number 로 추론 
그 이후에 d='hello' 넣게 되면 string 으로 추론하게 된다
