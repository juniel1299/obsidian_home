# 밈 콘텐츠 운영

- 이 프로젝트는 인스타그램 캐러셀과 유튜브 쇼츠용 밈 합성·편집·패러디 작업 공간이다.
- 조사와 제작 전에 `00_운영/레퍼런스_계정.md`를 확인한다. 사용자 지정 레퍼런스는 이 목록에 누적하며, 게시물 분석은 실제 확인한 근거로만 기록한다.
- 조사 채팅은 매일 한국 시간 20시에 국내 중심과 해외 응용 소재를 조사한다. 최근 7일을 보되 최근 24시간 변화를 우선한다.
- 조사 전 `01_소재함/트렌드/`의 기존 기록을 읽고, 새로운 확산이나 활용법 없는 소재는 반복 추천하지 않는다.
- 하루 최대 5개만 선정한다. 유행 근거가 부족하면 개수를 채우지 않는다. 접근 불가 자료와 확인 불가 수치는 명시하고 추측하지 않는다.
- 결과는 한국 날짜 기준 `01_소재함/트렌드/YYYY-MM-DD.md`에 저장한다. 소재 번호는 해당 날짜 안에서 고정하며 같은 날 재조사 시 기존 번호를 보존한다.
- 각 소재에 원본·참고 링크, 유행 근거와 확인 날짜, 웃음 포인트, 패러디 아이디어, 적합한 포맷, 필요한 제작 작업을 기록한다. 관찰된 사실과 제작 아이디어를 구분한다.
- 매일 조사 결과를 채팅에 보고한다. 새 소재가 없으면 그 사실과 조사 범위·한계를 짧게 보고하고 문서에도 기록한다.
- 제작 채팅에서 날짜와 번호로 소재를 지정하면 공유 문서를 먼저 읽는다. '어제'는 Asia/Seoul 날짜 기준이다. 해당 날짜 파일이 없으면 다른 날짜로 임의 대체하지 않는다.
- 조사만으로 이미지·영상 생성, 유료 작업, 외부 게시를 시작하지 않는다. 소재 선택 후 사용자가 요청한 제작을 진행한다.
