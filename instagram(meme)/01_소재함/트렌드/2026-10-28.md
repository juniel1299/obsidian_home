## 1. 국내: ‘이거 제 이모지야’ 자기소개 패러디

- 원본·참고: [에스콰이어 코리아 자기소개 영상](https://www.instagram.com/reel/Degyrp0PL1Q/), [@baechuu___ 패러디](https://www.instagram.com/reel/DespWT1TB37/). 고구마팜이 연결한 직접 링크를 확보했으나 Instagram 요청 제한으로 원본 재생·게시일·수치를 직접 확인하지 못했다.
- 확인일: 2026-10-28 KST. 매체 본문 확인, SNS 직접 확인 실패. 27일 기사에는 시각이 없어 최근 24시간 안의 보도인지는 확정하지 않는다. 원본·패러디의 정확한 발생일과 최근 하루 증가량도 미확인.
- 판단: 국내에서 자기소개를 제품·직업으로 바꾼 활용이 소개돼 선정. NEON AI 춤과는 다른 포맷이며 이전 선정 소재와 겹치지 않는다. 조회수·공유 수는 싣지 않는다.

- 패러디: ‘안녕하세요, 퇴근찡입니다’ → 반짝이는 소개 자세 → 배터리 1% 모양의 자체 아이콘 → ‘제 매력은 잔여 연차예요’. 또는 냉장고에 남은 반찬의 자기소개.
- 적합한 포맷: 8~12초 쇼츠. 인사 → 이모지 표정/아이콘 공개 → 자기소개 한 줄 반전. 캐러셀은 프로필·아이콘·현실 공개의 3장.

- 다음 확인: 원본 게시일과 새 사용자 변형 확보. 같은 자기소개를 다시 발견하는 것만으로 재선정하지 않는다.

## 3. 해외 응용: Firefox가 소환한 ‘옛날 밈 동창회’

### 관찰 사실과 유행 근거
- [Mozilla 공식 10월 25일 발표](https://blog.mozilla.org/en/firefox/come-back-to-firefox/)는 과거 인터넷 밈 주인공들을 다시 모은 캠페인을 소개한다. [공식 페이지가 연결한 원본 영상](https://www.youtube.com/watch?v=E2AoYIKwJqM)은 임베드 열기에서 JavaScript 실행 오류가 나 재생하지 못했다.
- [KYM 10월 27일 보도](https://trending.knowyourmeme.com/editorials/firefox-just-reunited-some-of-the-internets-most-iconic-early-memes-in-a-nostalgic-new-ad)는 광고 재공유와 출연자의 후속 비하인드 게시물을 다뤘다. [Reddit 재공유 사례](https://www.reddit.com/r/nostalgia/comments/1xgemof/firefox_bringing_back_og_internet_memes_in_ad/)도 검색 결과에서 확인했다. Reddit 본문·영상 재생은 확인하지 않았다.
- 확인일: 2026-10-28 KST. 공식 발표와 KYM 본문 확인. KYM이 보도한 Instagram·YouTube 조회수는 직접 검증하지 못해 실측 수치로 옮기지 않는다. 유료 캠페인 효과와 자연 확산의 비중도 미확인.
- 판단: 신규 밈 캐릭터보다는 옛 밈을 현재 상황에 다시 연결한 이번 주 재확산 사례다. 국내 유행으로 단정하지 않으며 한국에 응용할 제작 참고로 선정했다. 최근 24시간 증가량은 미확인.

### 제작 아이디어 — 관찰 사실과 구분
- 웃음 포인트: 한때 모든 상황을 해결하던 옛 인터넷 말투가 지금의 평범한 문제를 만나 엉뚱하게 재등장한다.
- 한국 응용: ‘옛날 댓글들이 단톡방에 복귀했다’라는 자체 상황극. 서로 다른 시대의 댓글 말투를 한 사람이 연기하고, 점심 메뉴 투표 하나를 장대한 동창회처럼 처리한다. 실제 밈 주인공이 출연한 듯한 합성은 사용하지 않는다.
- 적합한 포맷: 캐러셀 5장(옛 말투 입장 → 대화 → 세대차 → 메뉴 결정 → 현재의 나), 또는 20초 1인 다역 쇼츠.
- 필요한 제작 작업: 말투별 캐릭터 대본, 가상 채팅 화면, 자체 연기·녹음, 캐릭터별 자막 색과 반응 컷. 원본 광고의 장면 전개를 그대로 복제하기보다 동창회라는 발상만 응용한다.
- 다음 확인: 한국어권의 독립적인 재해석이나 후속 패러디가 확인될 때 재선정한다.
