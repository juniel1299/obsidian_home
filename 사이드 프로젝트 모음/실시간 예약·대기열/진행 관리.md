- 가입 없이 체험을 시작해 대기 1번이 되고, 샘플 참가자를 취소하면 기존 승격 로직을 거쳐 페이지 이동 없이 예약 확정으로 바뀐다. 처음부터 다시 체험할 수 있다.
- 방문자별 회차 격리를 서로 다른 브라우저에서 확인했다. 다른 방문자의 회차에는 404, 운영자 API에는 403을 반환한다. 체험 시작 한도는 IP당 15분에 10회다. 체험은 30분 뒤 만료되고 만료 데이터는 10분 주기로 정리한다.
- 백엔드 253개와 운영 빌드 Playwright 21개가 통과했다. 실패와 건너뜀은 0개이며 타입 검사와 ESLint도 통과했다.

다음 산출물은 검증된 공개 HTTPS URL이다. 호스팅·비용·주소, PostgreSQL과 백업, 운영자 계정 생성 방식을 결정한다. 첫 배포는 백엔드 단일 인스턴스를 기본안으로 두고, 증설 시 세션 공유를 설계한다. 배포 뒤 모바일·시크릿 창에서 가입 없는 체험, HTTPS 쿠키, 방문자 IP 집계, 백엔드 직접 접근 차단을 확인한다.
