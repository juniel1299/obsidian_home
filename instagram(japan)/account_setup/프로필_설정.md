# juniel 인스타그램 계정 설정

## 현재 상태
프로필 이미지와 문구 준비 완료. 신규 계정 생성, 아이디 사용 가능 여부, 크리에이터 전환, 2단계 인증은 아직 완료되지 않음.

## 아이디 후보
1. juniel.kr
2. juniel_korea
3. korea.with.juniel

## 표시 이름
ジュニエル｜韓国のトレンド・旅・日常

## 소개 — 아래 세 줄 복사
韓国人ジュニエルが、韓国の「今」をお届け🇰🇷
話題のグルメ・カフェ・トレンド・日常
韓国旅行にも、毎日の情報チェックにも。

## 휴대폰 앱에서 진행
- [ ] 프로필 → 상단 계정 이름 → 계정 추가 → 새 계정 만들기
- [ ] 위 후보 순서로 아이디 확인
- [ ] 운영용 이메일, 고유한 비밀번호, 실제 생년월일 입력 및 본인 인증
- [ ] 가입 약관 확인 후 직접 가입 완료
- [ ] 표시 이름과 소개 입력, juniel-profile.png 업로드
- [ ] 연락처 동기화 건너뛰기
- [ ] 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 크리에이터
- [ ] 디지털 크리에이터 카테고리 선택, 카테고리 표시 숨기기
- [ ] 계정 센터 → 비밀번호 및 보안 → 2단계 인증 설정
- [ ] 복구 코드는 비밀번호 관리자 등 안전한 곳에 보관 (이 폴더나 채팅에는 저장하지 않기)
- [ ] 기존 계정과 전환, 공개 프로필, 프로페셔널 대시보드 확인

메뉴 이름은 앱 버전에 따라 다를 수 있음.
