주요 문제 해결

01. Oracle IN 절 1,000건 제한 대응

  -​   문제 다중 선택 검색 조건에서 IN 절에 1,000개 초과 값 전달 시 SQL 오류 발생

  -​   해결 MyBatis 동적 SQL로 조회 조건을 일정 단위로 분할하고 OR 조건으로 연결하는 공통

       SQL 처리 로직 구현

  -​   결과 검색 조건 개수와 관계없이 조회 가능하도록 개선하고 여러 화면에서 공통 로직

       재사용


02. 대용량 조회 및 Excel 다운로드 메모리 문제 개선


  -​   문제 대용량 데이터를 일괄 조회·처리하면서 서버 메모리 사용량 증가 및 서버 중단 발생

  -​   해결 일반 조회는 OFFSET / FETCH 기반 DB 페이징을 적용하고, Excel 다운로드는

       5,000건 단위로 분할 조회·순차 처리

  -​   결과 메모리에 한 번에 적재되는 데이터량을 제한하여 대용량 처리 과정의 서버 중단 문제

       해결


03. 통계 Batch Timeout 개선


  -​   문제 Dashboard 통계 데이터 생성 과정에서 처리 데이터 증가로 Timeout 발생

  -​   해결 PL/SQL에서 필요한 값을 변수로 관리하고 데이터를 가공한 뒤 Insert하도록 처리

       구조 개선

  -​   결과 대량 통계 데이터 생성 Batch가 중단되지 않고 수행될 수 있도록 개선
