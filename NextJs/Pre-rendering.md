# 사전 렌더링

브라우저 요청에 대해 사전에 렌더링이 완료된 HTML을 응답하는 렌더링 방식 

CSR (Client Side Rendering) (리액트의 렌더링 방식) 방식의 단점을 해결 

## CSR 방식 
1. 유저가 서버에 접속 요청
2. 서버가 index.html (빈 내용) 을 브라우저에 전달 
3. 브라우저가 받은 index.html 유저에게 전달
4. 리액트로 만든 JS 파일의 묶음 (JS Bundle)을 브라우저에 전달 
5. 브라우저는 JS 를 리액트로 실행
6. 브라우저가 유저에게 컨텐츠 렌더링해줌

(JS Bundle 안에는 서비스에 존재하는 모든 컴포넌트 코드가 존재 -> 한번 접속하면 서버 요청 할 필요 x ,)
- 장점 : 페이지 이동이 매우 빠르고 쾌적하다

## 사전 렌더링 방식
1. 유저가 서버에 접속 요청 
2. 서버에서 JS 실행 (렌더링) (리액트)
