# Claude 로 옵시디언 노트 → 티스토리 글 만들기
공부하면서 정리한 옵시디언 노트를 Claude Code 로 블로그 원고로 다듬는 방식

## 전체 흐름
1. 볼트 폴더에서 Claude Code 실행 (옵시디언 MCP 도 연결 → [[옵시디언 Claude MCP 연결]])
2. 쓸 만한 노트 찾기 + 블로그 중복 확인
3. 원고 작성 (원본 노트는 그대로 , 새 파일로)
4. 티스토리 마크다운 모드에 붙여넣기 → 카테고리 , 태그 설정 → 발행
5. 후보 목록 상태 갱신

## 1. 중복 확인 : 사이트맵
이미 쓴 주제를 또 쓰지 않기 위해 블로그 발행 글 제목을 먼저 모음

티스토리는 `블로그주소/sitemap.xml` 에 모든 글 주소가 있음
```bash
# 글 번호 목록
curl -s https://problem-child.tistory.com/sitemap.xml \
  | grep -oE 'problem-child\.tistory\.com/[0-9]+<' | grep -oE '[0-9]+'
```
각 글 페이지의 `<meta property="og:title">` 에서 제목을 가져옴
→ 75개 제목과 볼트 노트 주제를 비교해서 안 쓴 것만 후보로

실제로 찾아보니 처음 추천받은 Shadow DOM , Redux 는 이미 발행한 글이었음
(→ 중복 확인을 먼저 하는 게 중요)

## 2. 후보 고르는 기준
- 노트 크기 , 코드 / 설명 비율 (완성도)
- 블로그에 아직 없는 카테고리 / 시리즈가 끊긴 곳 (예 : 자바 시리즈가 상속에서 멈춤)
- 기존 글 형식 (`A vs B`) 과 잘 맞는지
- 목록은 `블로그 글 아이디어 정리/발행 후보 목록.md` 에 저장 → 나중에 "2번 써줘" 로 요청

## 3. CLAUDE.md : 규칙을 한 번만 적기
볼트 루트에 CLAUDE.md 를 두면 Claude Code 가 세션 시작할 때마다 자동으로 읽음
→ 매번 문체 , 형식을 설명할 필요가 없어짐

적어둔 내용
- 블로그 주소 , 카테고리 구조 (티스토리는 2단계까지만)
- 글 요청 받았을 때 순서 (중복 확인 → 원고 → 기술 검증 → 목록 갱신 → 태그 제안)
- 문체 : 반말 서술체 , `(ft. 비유)` 제목 , 짧은 문단 , 비교표 , 내부 링크
- **실무 경험은 지어내지 말 것** (직접 주는 내용만)
- 티스토리 변환 규칙
- 태그 규칙 (5~8개 , 영문 + 한글 쌍)

## 4. 옵시디언 → 티스토리 변환
티스토리 마크다운 모드는 옵시디언 전용 문법을 모름

| 옵시디언 | 티스토리 원고 |
|---|---|
| `[[위키링크]]` | 일반 텍스트 또는 블로그 링크 |
| `![[이미지.png]]` | 이미지 직접 업로드 필요 → 가능하면 텍스트 트리 , 표로 대체 |
| `> [!note]` 콜아웃 | 일반 인용문 |
| frontmatter | 제거 |

## 5. 원본 노트의 오류 잡기
공부할 때 쓴 노트라 틀린 부분이 있음 → 원고 쓸 때 같이 검증

Next.js 글 쓸 때 실제로 고친 것
- `revalidatePath('tag')` → 태그 재검증은 `revalidateTag`
- `{cache: {next: {revalidate: 3}}}` → `{next: {revalidate: 3}}`
- Next.js 15 부터 fetch 기본값이 캐싱 안 함으로 바뀐 내용 추가
- Server Action 예제에 `<form action={...}>` 연결 누락

## 결과
- 원본 노트 2개 (Page Router 17KB + App Router 23KB) → 비교 원고 1편 (약 1만 자)
- 이미지 4장 → 텍스트 트리 + 비교표로 대체해서 업로드할 이미지 0장
- 새 카테고리 `JavaScript > Next.js` 생성 , 태그 8개

## 느낀 점
- 사용자가 직접 확인 / 판단해야 할 부분 : 카테고리 생성 , 실무 경험 , 최종 발행 , 티스토리 미리보기
- (여기에 직접 써본 소감 추가)
